TROUBLESHOOTING:
═════════════════

Setup fails?

  → Run setup.bat from the project folder

Port 8000 in use?
  → Run: python manage.py runserver 8001

Can't login to admin?
  → Run: python manage.py createsuperuser

Database error?
  → Run: python manage.py migrate

GitHub push fails?
  → Install Git (git-scm.com)
  → Run push-to-github.bat from the project folder
