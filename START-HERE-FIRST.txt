                                        TROUBLESHOOTING TIPS
═════════════════════════════════════════════════════════════════════════════════════════════════════════════════

Setup won't start?
→ Make sure Python is installed (python.org)
→ Close antivirus temporarily if it blocks

Port 8000 in use?
→ Run: python manage.py runserver 8001

Can't access admin?
→ Run: python manage.py createsuperuser

Screenshots won't save?
→ Make sure folder is not read-only
→ Try different screenshot tool

GitHub push fails?
→ Install Git (git-scm.com)
→ Check internet connection
